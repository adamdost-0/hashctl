# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/adamdost-0/hashctl/issues) to track
bugs and feature requests. Please search the existing issues before filing a new one to
avoid duplicates. For a new issue, open a fresh issue using the appropriate template.

For how-to questions and usage help, start with:

- The [README](README.md) and the `docs/` directory.
- `hashctl help` or `hashctl <command> --help` for built-in command documentation.

## Reporting security issues

Do **not** open a public issue for security vulnerabilities. Follow the process in
[SECURITY.md](SECURITY.md) instead.

## Support Policy

Support for `hashctl` is limited to the resources listed above and is provided on a
best-effort basis by the maintainers.
